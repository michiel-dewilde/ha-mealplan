# Code of Conduct

## The short version

Be decent to each other. This is a small project about groceries; nothing here
is worth being unpleasant over.

## What is expected

- Assume the other person is acting in good faith.
- Criticise code and ideas, not people.
- Accept that maintainers have limited time, and that "no" is a complete answer.
- Respect that people contribute in a second language, on their own time.

## What is not acceptable

Harassment, personal attacks, discriminatory remarks, deliberate intimidation,
publishing others' private information, and sustained disruption of discussions.

## Scope

This applies to issues, pull requests, discussions and any other space where
someone is representing the project.

## Enforcement

Report problems to the maintainer through a GitHub issue, or privately if the
matter is sensitive. Reports are handled confidentially. Responses range from a
request to stop, through removal of comments, to blocking from the repository —
whatever the situation warrants.
